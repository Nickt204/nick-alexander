## Quick snapshot

- **What:** Artist portfolio website for Nick Alexander — a dark, design-led React site that showcases artwork and tells the story behind it.
- **Stack:** React 19, Vite, Framer Motion, plain CSS (no utility framework).
- **Goal:** Sell work, grow profile, attract commissions — while communicating Nick's artistic identity and brand.
- **Status:** Live on Netlify (auto-deploys from `main`). Artwork data is in `src/data/artworks.js`. See [deployment.md](./deployment.md).
